## 🚀 Featured Project

### 🔥 [MLBox](https://github.com/mohittt-vermaa/MLBox) — All-in-One ML & AI Platform
A comprehensive ML/AI toolkit that brings together classification, regression, clustering, NLP, computer vision, explainability, and AutoML in one place — all running 100% locally.
- ✅ 12+ ML algorithms with preprocessing & model tuning
- 🤖 NLP (sentiment analysis, summarization, NER), Computer Vision (classification, face detection, OCR)
- 🧠 AutoML for automatic model selection & hyperparameter tuning
- 📊 EDA, interactive visualizations, and model explainability (SHAP/LIME)
- 💾 Trained-model export (`.pkl` / `.joblib`)

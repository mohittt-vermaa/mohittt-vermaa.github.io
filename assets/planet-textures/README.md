# Planet texture attributions

The compressed, resized equirectangular texture maps in this folder are used by the lock-screen Three.js solar-system scene. They were derived from the corresponding texture files in [maginkaaa/CG-Project-SolarSystem](https://github.com/maginkaaa/CG-Project-SolarSystem), whose credits identify the original image sources below. Image rights remain with their respective creators and are not claimed by this site.

- Mercury — [Solar System Scope texture on Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/2/27/Solarsystemscope_texture_8k_mercury.jpg)
- Venus — [Solar System Scope surface texture on Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/1/1c/Solarsystemscope_texture_8k_venus_surface.jpg)
- Mars — texture distributed with the credited project; original source was not separately identified.
- Jupiter — [Hubble OPAL global map, Planetary Science Institute](https://planetary.s3.amazonaws.com/web/assets/pictures/20181107_hlsp_opal_hst_wfc3-uvis_jupiter-2017a_color_globalmap2.jpg)
- Saturn — [Solar System Scope texture on Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/1/1e/Solarsystemscope_texture_8k_saturn.jpg)
- Uranus — [Pixabay image credited by the source project](https://t4.ftcdn.net/jpg/03/38/48/79/360_F_338487951_noDUtHlzxljulqg525A9YZAup9IEpeNS.jpg)
- Neptune — [Solar System Scope texture on Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/1/1e/Solarsystemscope_texture_2k_neptune.jpg)
- Sun — [Solar System Scope texture on Wikimedia Commons](https://upload.wikimedia.org/wikipedia/commons/c/cb/Solarsystemscope_texture_2k_sun.jpg)

The local files have been resized to 1536 × 768 and JPEG-compressed for faster page loading. Earth continues to use the Earth map already present under `assets/textures/`.

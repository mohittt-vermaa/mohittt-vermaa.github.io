🤖 Jarvis-IG Setup Tutorial

Step-by-step guide to set up your Instagram auto-reply bot on Android (Termux) and PC. Follow along!

Step 0

📱 Install Termux from F-Droid

First, install Termux on your Android phone. Do NOT use the Play Store version — it's outdated. Use F-Droid instead.

  1. Open your phone browser and go to: f-droid.org/packages/com.termux
  2. Download and install the APK
  3. Allow "Install from unknown sources" if prompted
  4. Open Termux — you'll see a black terminal screen
💡 Tip: Termux is like a mini Linux terminal on your phone. All commands below are typed in this terminal.
Step 1

📦 Install Required Packages

Copy-paste these commands one by one into Termux. Press Enter after each line.

Termux
~ $ pkg update -y && pkg upgrade -y
Hit:1 https://termux.net stable InRelease
All packages are up to date.
~ $ pkg install python python-pillow libjpeg-turbo -y
python is already the newest version (3.13.x).
Installing: python-pillow libimagequant libraqm
Setting up python-pillow (12.2.0) ...
All done!
⚠️ Important: If you see "already installed" — that's fine, just continue to the next step.
Step 2

⬇️ Download the Bot

This downloads the bot file directly from GitHub — no git clone needed!

Termux
~ $ curl -o ig_bot.py https://raw.githubusercontent.com/mohittt-vermaa/Jarvis-IG/main/jarvis_ig/ig_bot.py

Downloaded ig_bot.py (9.6 KB)

Step 4

🔐 2FA / Login Approval

If you have Two-Factor Authentication enabled on Instagram (recommended!), the bot will ask for your 6-digit code.

💡 Tip: You'll only need to enter 2FA once — the bot saves your session for next time!
⚠️ "Challenge Required"? If Instagram asks for security check — open the Instagram app, approve the login ("Was this you?"), then press Enter in Termux to continue.

Step 6 (Optional)

🔄 Running 24/7 in Background

Want the bot to keep running even when you switch apps? Follow these steps:

  1. Go to Android Settings → Apps → Termux → Battery
  2. Select "Unrestricted" (disables battery optimization)
  3. The bot will now keep running in the background!
💡 Advanced: For true 24/7 (even when phone is off), host the bot on a free cloud like PythonAnywhere or Render. See the README for cloud hosting instructions.

Step 0

💻 Prerequisites

Make sure you have Python 3.9+ installed on your PC.

  • Download Python from python.org (Windows) or use your package manager (Mac/Linux)
  • Make sure to check "Add Python to PATH" during installation (Windows)
  • Open Command Prompt (Windows) or Terminal (Mac/Linux)
Step 1

📦 Install Dependencies

C:\Users\Mohit> pip install Pillow pydantic instagrapi
